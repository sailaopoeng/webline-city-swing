# Webline MVP

## Run and structure

Open `index.html` in a modern browser, or run `python3 -m http.server` here. There is no build step, dependency, backend, or game engine. `index.html` owns the canvas and HUD; `style.css` owns the responsive overlay; `game.js` is one small IIFE with functions for input, world generation, physics, collision, camera, and drawing. Keep the project plain HTML/CSS/JavaScript and Canvas unless the scope changes.

Hosting is AWS only (the ChatGPT Sites copy in `dist/` and `.openai/hosting.json` was retired). S3 + CloudFront is defined in `infra/aws/webline-site.yaml` and deployed by `.github/workflows/deploy-aws.yml` on pushes to `main`; it uploads the root `index.html`, `style.css`, and `game.js` directly. Setup and domain cutover steps are in `infra/aws/README.md`. New static assets must be added to that workflow's staging step and `paths` filter. Never commit AWS keys; the workflow uses GitHub OIDC and repository variables.

## Physics and game loop

World coordinates use CSS pixels, with positive Y downward. `requestAnimationFrame` draws; `frame()` advances physics in fixed `1/120` second steps and caps catch-up after a stalled frame. Gravity and automatic rightward acceleration update velocity before position. A web attaches to a selected visible mast node above the player, usually ahead. Its length is set from the current distance; the rope may slacken, but when stretched `constrainRope()` projects the player back to the rope length and removes only outward radial velocity. Tangential velocity remains, so release preserves swing momentum. Speed is capped. `collide()` allows downward roof landings, kills on walls, red spikes, or falling below the view. Camera X eases to keep the player about 28% from the left edge.

## Levels, points, and pickups

There are 100 levels. `startLevel()` builds each one from the same safe runway; the finish gate sits `levelBaseLength + levelLengthStep × (level − 1)` metres out (10 px per metre) on a wide, hazard-free finish roof placed by `generateAhead()`. Crossing the gate alive calls `clearLevel()`: state `levelclear`, confetti, the hero dances, and a card shows run points, clear bonus (`500 + 50 × level`), time bonus against par (`length / parSpeed`), and 1–3 stars. The next level starts after `levelClearAutoSeconds` or on Enter/Space/the button, with its number and district on the countdown and a short banner. Difficulty is level-based, not distance-based: `levelScaled()` interpolates each `[level 1, level 100]` pair in `TUNE` linearly (about 1% per level). Every ten levels is a district in `DISTRICTS` with its own palette. After level 100 the card says City Conquered and waits for the player, then the game runs endless mode (level 101, shown as ∞) at max difficulty with no gate.

Each level allows `attemptsPerLevel` attempts, refilled when a level is cleared. Death uses one; running out sends the run back to level 1 with zero points. Endless deaths are free. Points are banked per cleared level; the live total is banked points + metres × level multiplier (`1 + 0.1 × (level − 1)`) + bonuses (web combo when attaching in the air without touching a roof, near misses over spike tips, glide distance, tokens). `localStorage` keeps `webline-progress` (level, banked points, attempts left), `webline-best-points`, and `webline-best-level`; all storage is optional. `?level=N` starts at level N for testing.

`placeItems()` puts power-ups over gaps and token arcs under masts, with level-scaled chances. Rocket Boots add thrust and lift for `boostSeconds` with a higher speed cap that eases back afterwards, and block webs while firing. A Glide Feather adds a glide charge. The Wingsuit improves glides for the level. A Shield survives one spike or wall hit (a wall hit vaults the hero onto that roof) with brief invulnerability. A Web Magnet scales attachment range and pulls tokens. Glide is a charge (max `maxGlideCharges`) earned every `glideSwingCount` airborne releases or from pickups; `autoGlide()` opens it when falling over a gap toward the next roof.

## Controls and state

Each level starts with a three-second countdown showing the level, district, goal, and attempt; a gameplay key or tap skips it, while R restarts it and Esc pauses it. The hero starts grounded on a long hazard-free first roof, with reachable masts near the beginning and the far edge. Hold Space, mouse, or touch to attach/maintain the web; release to detach. Holding while no node is in range retries attachment every 0.09 seconds. The selected eligible node is marked by a ring. Press V or use the Jump button to jump while grounded; in the air with a glide charge, the same input opens a glide (the button reads GLIDE then). Hold Up/W or the Shorter button to reel in an attached web; hold Down/S or the Longer button to let it out within the configured rope limits. While on a web, tap Left/Right or A/D to pump the swing for extra tangential momentum. Esc or the Pause button pauses and resumes, clearing held inputs on pause. After death, only Enter or a mouse/touch click on the retry button continues (retry the level, or start from level 1 when out of attempts); a later key press or tap skips the countdown. While the death screen is visible the hero dances behind the card. R restarts the level: free during the countdown, costing an attempt once play has begun (on the last attempt it ends the run instead). Start over from level 1, on the pause and death cards, needs a second tap within three seconds. A set tracks simultaneous web input sources so releasing one does not detach another. Blur releases all inputs. Resizing restarts the current level without using an attempt because roof and mast heights depend on viewport height (during the clear card it moves on to the next level).

## Tuning

Change `TUNE` at the top of `game.js`: `gravity`, `horizontalStartingSpeed`, `airAcceleration`, `swingAcceleration`, `groundAcceleration`, `maxSpeed`, `maxFallSpeed`, `minRopeLength`, `maxRopeLength`, `attachmentRange`, `ropeConstraintStrength`, `jumpSpeed`, `ropeAdjustSpeed`, `countdownSeconds`, `playerRadius`, `buildingSpacing`, `cameraSmoothing`, and `simulationStep`. Keep `ropeConstraintStrength` at `1` for the current taut-rope behavior. Building widths, heights, mast placement, and vent chance are in `makeBuilding()`/`generateAhead()`; attachment scoring is in `findAnchor()`. Roof hazards are spike clusters of 2–3 triangles; tune `spikeBase` and `spikeGap`. Level settings: `levelCount`, `levelBaseLength`, `levelLengthStep`, `attemptsPerLevel`, `parSpeed`, `levelClearAutoSeconds`, and the level-1/level-100 pairs `gapScale`, `hazardChance`, `tripleSpikeChance`, `roofShrink`, `roofDrop`, `itemChance`, and `tokenChance`. Pickups: `pickupRadius`, `boostSeconds`, `boostThrust`, `boostMaxSpeed`, `boostLift`, `magnetSeconds`, `magnetRange`, `wingsuitGlide`; item weights and labels are in `ITEM_TYPES`. Glide: `glideSwingCount`, `maxGlideCharges`, `autoGlideMargin`, `glideGravity`, `glideMaxFallSpeed`, `glideAirAcceleration`, `glideLift`, and `glideMinSpeed`. Swing-pump strength is `swingPump`. Camera zooms out slightly at speed via `maxZoomOut`; motion trails fade in above half max speed.

## Current limits and checks

Attachment is automatic rather than aimed. Gap widths are capped per level but not proven solvable, and a badly timed swing can send the player backward. Level progress is saved, but there are no menus or audio yet (see Future plans). Before changing physics, run `node --check game.js` and play several hold/release/re-attach cycles at desktop and mobile sizes; verify roof landing, spike/wall/fall deaths, speed cap, rope length, glide charges and auto-glide, each pickup, swing pump, attach pulse, motion trail, camera zoom, level clear and the next countdown, attempts running out, City Conquered into endless (`?level=100`), and immediate restart. Avoid predefined swing arcs or release impulses that replace the momentum model.

## Decision record

`cae5728` added the countdown, controls, and hero animation to the original swing MVP (`5503f3b`). The previous airborne start left too little time before the first gap, so this follow-up starts grounded on a hazard-free 1180px roof with early and near-edge masts. Jump moved from Ctrl to V to avoid macOS Ctrl+Space input switching: left thumb holds Space, left index taps V, and the right hand uses Up/Down. Countdown R/Esc now reset/pause, and the Jump button starts play. Keep momentum-based swinging and these onboarding choices unless deliberately redesigning the controls or opening difficulty.

The levels update replaced the endless distance score with 100 levels, banked points, five attempts per level, saved progress, pickups, and glide charges, because a single endless run gave no goals or sense of progress. Distance-based difficulty became level-based (about 1% per level, linear) so a retried level stays the same difficulty. Glide became a stored charge, opened with V in the air or automatically over a gap, so earning it is never wasted on a bad release. The ChatGPT Sites copy (`dist/`, `.openai/`) was removed; AWS is the only host.
